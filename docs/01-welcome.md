# Welcome

**Skelril** is a survival game for [Luanti](https://www.luanti.org/), built on the Mineclonia base game. It is a rewrite of the
Grindstone server plugin: the same City, the same economy and the same custom items, rebuilt for Luanti.

This is the **player guide**: what you can do **today**. Features are added to it as they are implemented. The
[roadmap](/roadmap) shows what is planned.

| Section | What you will find |
| --- | --- |
| [Getting started](/guide/getting-started) | Your first day, and how your Grindstone inventory comes back to you. |
| [Protecting your stuff](/guide/protecting-your-stuff) | City protection, Ziggy claims, container locks and player combat. |
| [Mechanics](/guide/mechanics) | Wallet, lottery, market, highscores, warps and homes, portals, dying, sacrifices, item sorters, prayers, weather and the apocalypse. |
| [Guilds](/guide/guilds) | The Ninja and Rogue guilds and their level-based powers. |
| [Areas](/guide/areas) | The City, Astaria, Halzeil, the Grave Yard, the Cursed Mine, the Factory and the PvP arenas. |
| [Bosses](/guide/bosses) | Shnuggles Prime and Patient X. |
| [Mini-games](/guide/minigames) | Spleef. |
| [Items](/guide/items) | Custom weapons and their special attacks, armour sets, potions and utility items. |
| [Cheat sheet](/guide/cheat-sheet) | Every player command on one page. |

::: info Work in progress
Many features are written but not yet checked in a game client (guild powers, the warp menu's look, the bosses). The chapters
say so where it matters.
:::

Grindstone areas that are not here yet, such as Frostborn, the Freaky Four, Jungle Raid and Sky Wars,
are on the [roadmap](/roadmap).
