# Utility Items

| Item | Use |
| --- | --- |
| Tomes (Life, Sacrifice, Cleanliness, Poison, Cursed Smelting, Divinity, Legends, the Undead) | Use on a block to learn the tome for good (the tome is used up). Life keeps your belongings on death without gems, Sacrifice and Cleanliness improve sacrifices, Poison now and then turns poison into regeneration. The others take effect with the areas that use them. |
| Tome of the Rift Splitter | Pays for a personal [warp](/guide/mechanics/warps#making-warps). |
| Ninja Oath, Rogue Oath | Use on a block to join that [guild](/guide/guilds). |
| God Fish | Eat it: Hulk (strength, resistance, no hunger) for 5 minutes. |
| Chicken Hymn | Turns nearby items into chickens; using it again makes those chickens vanish, sometimes leaving cooked chicken. |
| Hymn of Harvest | Harvests the fully grown crops you can see within 5 blocks into your inventory and replants them. |
| Phantom Hymn | With Phantom Essence, carries you through the [Grave Yard](/guide/areas/graveyard#the-temple)'s creeper maze or to [Patient X](/guide/bosses/patient-x). |
| Pixie Dust | Use to fly fast for 15 seconds per dust while you stay in the air. |
| Magic Bucket | Use to fly or stop flying; sneak and use to change speed (slow, medium, fast). Use it on a cow for Mad Milk; drink Mad Milk to get the bucket back. Flight ends when you stop carrying the bucket. |
| Linear tools (axe, pickaxe, shovel) | Punch a block to dig a line of that block into the face you hit (Distance, default 3, up to 9). Sneak and use to change the distance. |
| Radial tools (axe, pickaxe, shovel) | Punch to dig the 3 x 3 square of that block around it. Sneak and use to switch between 3 x 3 and a single block. |
| Linear Block Placer | Hold it in your offhand: blocks you place continue into a line (Distance, change by punching; sneak to go down). |
| Phantom Link | Punch a container to link it; use the link anywhere to open that container while you stay put (you must be allowed to open it). |

Flying items never work where flying is not allowed, and they speed up walking too while active. Build tools may not be used in the City. All of these
are tested only without a game client so far.

## Summation

Right-click while holding a **Scroll of Summation** or **Hymn of Summation** in your main hand to compact materials. The scroll is consumed only when a conversion succeeds; the hymn is reusable and can also consolidate partial destination stacks without consuming anything.

The 17 source recipes cover bone meal, coal, raw metals, iron/gold nuggets and ingots, copper, redstone, lapis, diamonds, emeralds, netherite, slime and wheat. Each conversion uses nine ingredients for one result. Nugget conversions can continue through ingots to blocks in the same use.

Compaction uses your main inventory and offhand, placing results in storage slots before the hotbar. Named items and custom items are preserved. Armor and ender-chest contents are outside this operation. If the results will not fit, the inventory is unchanged and the scroll is kept.
