# Player Cheat Sheet

| Command | Does |
| --- | --- |
| `/activate <code>` | Activate a new account from the arrival room. |
| `/afk [status]` (`/away`) | Mark yourself away; people messaging you see the status. Moving or doing anything ends it. |
| `/balance` | Show your Skrin. |
| `/bank collect` | Collect a saved gold withdrawal. |
| `/bring <player>` | Accept a player's `/call`: they appear next to you. |
| `/buffs` | List your active temporary buffs. |
| `/call <player>` (`/tpa`) | Ask a player to bring you to them. |
| `/claim [info]` | Inspect the Ziggy claim here. |
| `/claim abandon [here]` | Withdraw from your unfrozen claims or just the current one. |
| `/claim show` | Highlight the claim boundary for ten seconds. |
| `/claim trust <player> [here]` | Grant build access to your claims or just this one. |
| `/claim trusted` | List your trust grants. |
| `/claim untrust <player> [here]` | Revoke build access to your claims or just this one. |
| `/clear [-a] [-s]` | Empty your inventory except the hotbar (`-a`: everything, armour too; `-s`: only what you hold). |
| `/forecast` | Show the weather forecast. |
| `/gamemode` (`/gm`) | Show your game mode. |
| `/guild enable\|disable\|level\|settings\|teleport` | Guild powers. |
| `/highscore [type]` | Open one score table. |
| `/highscores [filter]` | Open the Hall of Records. |
| `/home` | Go home. |
| `/invite [new]` | Create, or replace, your activation code. |
| `/ledger [time=7d] [limit=20]` | Your balance history: every change and why. |
| `/lock` | Then punch a container to lock it. |
| `/lottery buy [amount]` | Buy tickets. |
| `/lottery pot` | See the pot. |
| `/lottery recent` | Latest winners. |
| `/mirage ignore\|unignore <players>` | Stop or allow hurting them there. |
| `/mirage list [filter] [-p page]` | List the Mirage Arena maps. |
| `/mirage vote <map>` | Vote for the next map. |
| `/motd`, `/rules`, `/ping` | The welcome message, the rules, a quick "is the server there". |
| `/msg <player> <message>`, `/reply <message>` (`/r`) | Private messages; `/reply` answers the last one. |
| `/pay <player> <amount>` | Pay a player. |
| `/pr [-c] <player> <prayer>` | Short alias for `/pray`. |
| `/pray -l` | List the prayers you may use and their level costs. |
| `/pray [-c] <player> <prayer>` | Bless or smite an online player for 15 minutes. |
| `/pvp [-s]` | Toggle global PvP; `-s` toggles safe spots. |
| `/report [description]` | Open the report screen to tell the staff about a bug or problem. |
| `/return` (`/ret`) | Go back to where you were before your last teleport or death; repeat to go further back. |
| `/sacrifice value` | Value the item in your hand. |
| `/setwelcomelocation` | Set where players using your invite arrive. |
| `/sky accept` | Accept a sky world invite. |
| `/sky invite <player>` | Invite someone to the sky world (you must be there). |
| `/slay` | Kill yourself (when you are stuck). |
| `/sorter add source\|sink [mode]` | Then punch a container to add it. |
| `/sorter network create\|use\|list` | Make or pick an item sorter network. |
| `/spawn` | Go to the spawn of the dimension you are in. |
| `/spleef` | Show the spleef arenas. |
| `/unlock` | Then punch it to unlock. |
| `/warp <name>` | Teleport to a warp. |
| `/warps` | Open the warp menu. |
| `/warps destroy <name>` | Delete a personal warp. |
| `/warps list [-p page] [filter]` | List warps. |
| `/warps set <name>` | Save a personal warp here. |
| `/welcome` | Show the welcome text again. |
| `/whereami` | Show your coordinates, dimension and facing. |
| `/who [filter]` | List the players online (AFK players are grey). |
